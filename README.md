# 💧 Distribuição de Água

## 📌 Descrição

Exercício desenvolvido em **Java** para verificar se a quantidade de água disponível é suficiente para atender às necessidades de cinco cidades.

O programa recebe a quantidade total de água disponível e as necessidades de cada uma das cinco cidades. Em seguida, calcula a soma das necessidades e verifica se a água disponível é suficiente.

## 🛠️ Tecnologias

* Java
* `Scanner`
* Estruturas condicionais `if` e `else`
* Variáveis `int` e `double`
* Operações matemáticas

## 📥 Entrada

O programa recebe:

1. A quantidade total de água disponível.
2. A necessidade de água da cidade 1.
3. A necessidade de água da cidade 2.
4. A necessidade de água da cidade 3.
5. A necessidade de água da cidade 4.
6. A necessidade de água da cidade 5.

## 🧮 Funcionamento

Primeiro, o programa soma as necessidades das cinco cidades:

```text
soma = c1 + c2 + c3 + c4 + c5
```

Depois, compara o total disponível com a soma das necessidades.

### ✅ Água suficiente

Se a quantidade disponível for suficiente:

* Se não houver sobra:

```text
Abastece perfeitamente.
```

* Se houver sobra:

```text
Abastece e sobra: X.
```

### ❌ Água insuficiente

Caso a quantidade disponível seja menor que a necessidade total:

```text
Insuficiente.
```
